# Panel Cardón Pádel Club

Panel del dueño del club de pádel (demo, club ficticio). Una sola página (`index.html`) que lee los datos desde n8n y tiene un modo con datos de ejemplo.

- Turnos del día por cancha: tocá un turno para ver quién lo reservó, su teléfono y su historial.
- Jugadores, puntos y canjes, ofertas y horas valle.
- Se adapta al celular y tiene tema claro, oscuro o automático.

**Modo prueba:** no tiene usuario ni contraseña y solo muestra datos de la demostración. Antes de usarlo con jugadores reales hay que agregar acceso con clave.
